TalkTime

プライバシーポリシー

制定日：2026年11月15日

TalkTime（以下「本アプリ」）は、利用者の情報を大切に扱います。本アプリは次のとおり、個人情報を含むいかなるデータも収集しません。

収集する情報

本アプリは、利用者の個人情報、利用状況、端末の識別子、位置情報、連絡先などを一切収集しません。解析・広告・クラッシュ収集のためのツールも組み込んでいません。

通信

本アプリはインターネットとの通信を一切行いません。2台の時刻の同期は、利用者どうしが口頭・4桁のコード・リンクで終了時刻を伝え合うことで行い、サーバーを使いません。

共有するリンク（join.html）は GitHub Pages で公開している静的なページです。リンクに含まれるのはタイマーの終了時刻だけで、ページは外部のスクリプトや解析タグを読み込みません。なお、ページの配信元である GitHub はアクセスの記録を保持する場合があります（GitHub のプライバシーポリシーをご覧ください）。

端末に保存する情報

本アプリの設定（予告のタイミング、終了の知らせ方など）と、実行中のタイマーの状態（終了時刻など）は、利用者の端末の中にだけ保存します。これらが端末の外へ送られることはありません。アプリを削除すると、保存した情報も削除されます。

通知とアラーム

本アプリは、終了時刻と予告を知らせるために、端末の中で通知とアラームを予約します。これらの許可はいつでも iOS の「設定」で変更できます。

お問い合わせ

本ポリシーについてのお問い合わせは、GitHub の Issues からお願いします。

改定

本ポリシーを改定するときは、このページで告知します。

Privacy Policy

Effective: November 15, 2026

TalkTime (“the app”) does not collect any data, including personal information.

Information we collect

The app does not collect personal information, usage data, device identifiers, location, contacts, or any other data. It contains no analytics, advertising, or crash-reporting tools.

Network access

The app never connects to the internet. Two phones stay in sync because the people on the call share the end time by voice, with a 4-digit code, or with a link. No server is involved.

The shared link (join.html) is a static page hosted on GitHub Pages. The link contains only the timer's end time, and the page loads no external scripts or analytics tags. GitHub, which serves the page, may keep access logs (see GitHub's privacy statement).

Data stored on your device

Your settings (such as heads-up timing and alert style) and the state of the running timer (such as the end time) are stored only on your device and are never sent anywhere. Deleting the app deletes this data.

Notifications and alarms

The app schedules notifications and alarms on your device to alert you before and at the end time. You can change these permissions at any time in iOS Settings.

Contact

For questions about this policy, please use GitHub Issues.

Changes

If this policy changes, we will post the update on this page.
